# 🎮 CloudPlay - Xbox Cloud Gaming Booster & Client

Ứng dụng Android tối ưu hóa trải nghiệm chơi game đám mây Xbox Cloud Gaming (xCloud) với công nghệ **Direct Handshake Bypass** độc quyền, giúp game thủ Việt Nam chơi game server Nhật Bản/Hàn Quốc với độ trễ thấp nhất (~25 - 35ms) mà không cần duy trì kết nối VPN liên tục.

---

## 📥 Hướng dẫn Tải File APK (Download)

Nếu bạn gặp lỗi không tải được APK từ GitHub, hãy làm theo 1 trong 2 cách cực kỳ đơn giản sau:

### Cách 1: Tải trực tiếp từ mục Releases (Khuyên dùng)
1. Ở trang chính của repository GitHub này, nhìn sang cột bên phải và bấm vào mục **Releases** (hoặc truy cập đường dẫn: `https://github.com/<tên_tài_khoản>/<tên_repo>/releases/latest`).
2. Mở mục **Assets** ở cuối bản phát hành mới nhất.
3. Nhấp vào file **`CloudPlay-Xbox-v1.0.apk`** để tải về điện thoại và cài đặt.

---

### Cách 2: Tải từ mục Actions (Luôn có sẵn bản build mới nhất)
1. Bấm vào tab **Actions** ở menu phía trên repository GitHub.
2. Chọn workflow chạy gần nhất có tích xanh (ví dụ: *"Build & Release Android APK"*).
3. Cuộn xuống cuối trang đến phần **Artifacts**.
4. Nhấp vào **`CloudPlay-Xbox-APK`** để tải file zip chứa file APK đã được biên dịch sẵn.

---

### ⚙️ Lưu ý cấu hình GitHub Actions (Để tự động tạo mục Releases)
Nếu bạn đã Fork hoặc đẩy code lên GitHub của mình mà Actions báo lỗi không tạo được Release, hãy bật quyền ghi cho GitHub Token:
1. Vào mục **Settings** của repository trên GitHub.
2. Chọn menu bên trái: **Actions** -> **General**.
3. Kéo xuống mục **Workflow permissions**:
   - Chọn **Read and write permissions**.
   - Tích chọn ô **Allow GitHub Actions to create and approve pull requests**.
4. Bấm **Save**.
5. Vào tab **Actions** -> bấm vào workflow và chọn **Re-run all jobs**.
