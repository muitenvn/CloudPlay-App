📖 Overview
CloudPlay is an open-source Android client designed to optimize Xbox Cloud Gaming (xCloud) in Southeast Asia featuring Smart Region Bypass (25–35ms Ping), WebRTC 60 FPS Optimizer, AI Gaming Translator, and a Floating Game Bar HUD.

✨ Key Features
 * ⚡ Smart Region Bypass: Automatically detaches proxy after stream handshake for direct ISP connection (25–35ms ping, 0ms VPN overhead).
 * 🌐 AI Gaming Translator: Translates game menus and storylines while preserving copyrighted game titles and controller button tags.
 * 🎮 Floating Game Bar HUD: Real-time telemetry monitoring (Ping, FPS, Bitrate) with Clarity Boost Ultra.
 * 📶 Network Optimization: Custom profiles for 4G/5G data saving and Wi-Fi latency reduction.
