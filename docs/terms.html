3.3. Thông số kỹ thuật thực tế (FloatingHud): Đọc trực tiếp báo cáo RTCStatsReport từ kết nối WebRTC của trình duyệt để hiển thị tốc độ khung hình (FPS), độ phân giải thực tế, băng thông (bitrate), độ trễ vòng lặp (RTT ping), độ biến thiên trễ (jitter) và số gói tin bị mất. Ứng dụng không bao giờ hiển thị số đo giả tạo.

3.4. Quay màn hình nội bộ (ZeroLagScreenRecorder): Chỉ hoạt động khi Người dùng chủ động bấm nút Quay trong menu nổi trong lúc chơi. Tệp video .mp4 được lưu tạm thời tại thư mục riêng cacheDir/recordings/ trên thiết bị để Người dùng tự xem, lưu hoặc chia sẻ.

3.1. Browser Compatibility & Stream Adjustments (CloudBrowserScreen, XboxBridge):

  • Loads the official portal https://www.xbox.com/<locale>/play (or https://play.xbox.com/ depending on UI preference) and sets the locale cookie (MSPC-LOCALE) on .xbox.com.
  • Provides optional browser identification headers (User-Agent and Sec-CH-UA) emulating Desktop Edge/Windows or Mobile to support 1080p browser stream profiles.
  • Includes an optional feature to automatically dismiss the post-stream feedback modal when exiting a game to maintain interface stability.
  • Allows configuring target resolution (720p / 1080p), maximum bitrate limits, H.264 codec profile, aspect ratio scaling, CSS/WebGL clarity filters, and audio boost via WebAudio GainNode.

3.2. Touch & Physical Controllers (VirtualGamepad): Provides standard Xbox controller inputs (ABXY, D-Pad, LB/RB, LT/RT, L3/R3, View, Menu, Xbox Guide button, and dual analog sticks) translated into standard W3C Gamepad API events, alongside pass-through support for Bluetooth and USB-C controllers.

3.3. Real-Time Telemetry (FloatingHud): Reads live RTCStatsReport metrics directly from the active WebRTC peer connection to display actual FPS, resolution, bitrate, RTT ping, jitter, and packet loss. The Application never fabricates telemetry numbers.

3.4. Built-In Screen Recording (ZeroLagScreenRecorder): Activated only when the User manually taps the Record button in the floating menu. Video files (.mp4) are saved locally in cacheDir/recordings/ for the User to save or share.
